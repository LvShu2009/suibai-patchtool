# 酸败补丁助手

给手机游戏 **《300大作战》** 用的免 root 补丁安装工具。通过 **Shizuku**（无线调试/root 启动均可）或**设备 root** 直接写入游戏的 `Android/data/<包名>/files`，带原版备份与一键回滚。

当前版本：**v3.4.3（完全本地版）**

> 本版**不联网**、不申请 `INTERNET` 权限，所有补丁都由你手动放进 `补丁存放位置（zip）/`。
> 仓库只开源本地版；带「在线补丁中心」的构建不作为开源发布（那部分只是下载站网页的壳，与补丁资源无关）。

## 功能

| 功能 | 说明 |
|---|---|
| ▶ 一键安装补丁 | 把 `补丁存放位置（zip）` 里的 zip 解压并覆盖进游戏目录 |
| 🩹 反和谐安装 | 在游戏 files 下建 `localmode.txt` |
| ↩ 一键回滚原版 | 按备份索引逐字节校验后还原 |
| 🧹 清理备份 | 清掉多余备份，保留 `原版` |
| 🗑 删除已安装的补丁 zip | 只清补丁目录里的 zip，不动游戏与备份 |
| 📦 打包 | 把 `打包补丁/待打包资源` 打成可安装的 zip |
| 🔍 自动探测 | 找出已安装的酸败目录（官服 / 渠道服） |

### 解包与资源定位（v3.4.3）

安装前做三级定位，**绝不靠"名字像"猜**：

1. **精确路径**（含逐级剥皮）：`李白/role/x.assetbundle` → `role/x.assetbundle` → `x.assetbundle`
2. **同名唯一**：全盘只有一个同名文件才用
3. **同名多个 + CAB 双条件校验**：读补丁 ab 头部的 `CAB-xxx`，与游戏侧候选的 CAB 比对，
   相同才装（命中多个则全装，游戏复用同一资源）；全不同就整个跳过

另外：zip 支持 **GBK 文件名**；说明/预览文件（png/jpg/md/txt，`localmode.txt` 例外）不往游戏目录塞。

首次安装会建 CAB 索引（约 1~2 分钟），缓存到 `<补丁根目录>/缓存/资源索引/`。

## 两条执行通道

- **root（su）**：真 uid=0，走 `/data/media/0`，不经过 FUSE，还能写 root 拥有的目录
- **Shizuku**：shell(uid=2000) 或 root(uid=0)；shell 下偶发挂载点失效（`Transport endpoint is not connected`），v2.3 起有开跑前自检，会直接拒绝而不是装一半

## 安全设计

- 备份按包名分目录：`备份文件/<包名>/原版/`，官服与渠道服互不覆盖
- 备份只做一次：已备份的文件永不覆盖；当前内容与补丁相同时判定"不是原版"，跳过
- 回滚前校验：索引里的 crc+size 与备份文件不符会拒绝还原
- 所有脚本操作写日志到 `操作日志/`

## 自己编译

需要 JDK 17、Android SDK build-tools（aapt/zipalign/apksigner）与 `r8.jar`：

```sh
bash build.sh
```

产物在 `build/酸败补丁助手.apk`。

> Shizuku 的 AAR 需要放在 `$TOOLS/{api,prov,aidl,shared}/classes.jar`（脚本里已有路径），
> 仓库里不带这几个 jar，请按 build.sh 里的变量自行放置。

## 目录约定

```
LvShu/酸败补丁/
├── 酸败补丁助手.apk
├── 补丁存放位置（zip）/     # 把补丁 zip 放这里
├── 操作日志/                # 每次操作一个日志文件
├── 备份文件/<包名>/原版/    # 自动备份的原版文件 + .manifest.tsv 索引
├── 临时解压/                # 运行时临时目录，可清空
├── 补丁素材源文件/
├── 打包补丁/待打包资源/
└── SU脚本_修订版/
```
