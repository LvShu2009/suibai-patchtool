# 酸败补丁助手（本地版）

给手机游戏 **《300大作战》** 用的补丁安装工具。通过 **Shizuku**（无线调试 / root 启动均可）或**设备 root** 直接写入游戏的 `Android/data/<包名>/files`，带原版备份与一键回滚。

当前版本：**v3.15.3**（versionCode 39）

> 本版为**纯本地版**：不申请 `INTERNET` 与 `ACCESS_NETWORK_STATE` 权限，不含在线补丁按钮、WebView 在线中心或任何第三方补丁站点地址。
> 所有补丁都由你手动放进 `补丁存放位置（zip）/` 后安装。

## 下载

- APK：`dist/patchtool-v3.15.3.apk`
- 完整工具包：`dist/patchtool-kit-v3.15.3.zip`（含 APK、源码、SU 脚本、操作指南、图标）

## 两条执行通道

- **root（su）**：真 uid=0，走 `/data/media/0`，不经过 FUSE，可写 root 拥有的目录
- **Shizuku**：shell(uid=2000) 或 root(uid=0)；开跑前有自检，挂载点失效会直接拒绝而不是装一半

## 功能

| 功能 | 说明 |
|---|---|
| ▶ 一键安装补丁 | 把 `补丁存放位置（zip）` 里的 zip 解压并覆盖进游戏目录 |
| 🩹 反和谐安装 | 在游戏 files 下建 `localmode.txt` |
| ↩ 一键回滚原版 | 按备份索引逐字节校验后还原 |
| 🧹 清理备份 | 清掉多余备份，保留各包名下的原版 |
| 🗑 删除已安装的补丁 zip | 只清补丁目录里的 zip，不动游戏与备份 |
| 📦 打包 | 把 `打包补丁/待打包资源` 打成可安装的 zip |
| 🔍 自动探测 | 找出已安装的酸败目录（官服 / 渠道服） |

## 解包与资源定位

安装前按优先级定位，**绝不靠“名字像”猜**：

1. **绝对路径优先**：带 `files/` 根的条目直接按 `/files/` 后的路径落位；
2. **精确路径 + 逐级剥皮**：`李白/data/...` → `data/...`，用来找游戏里已有的资源；
3. **同名唯一**：全盘只有一个同名文件才用；
4. **同名多个 + CAB 双条件校验**：读补丁 ab 头部的 `CAB-xxx`（锁 32 位），与游戏侧候选比对，相同才装。

游戏资源在 `files` 下的 `data` 与 `flies` 两个目录，资源清单与 CAB 索引都同时扫这两处；`files` 根目录一层的文件（`localmode.txt`、`server_assetslist.json`、`version.json`、`LocalSetting.txt`、`serverlist20191202.txt`）也进清单，根目录的音频/图片不进。路径归一化的原则是**只剥多余的层**：`flies` 是真实目录，单层 `flies/data/...` 原样保留，双层 `flies/flies/data/...` 只剥掉第一层落到第二层，不会无脑剥光；作者自建包装目录（如 `李白/data/...`）才会被剥掉。

游戏里没有对应资源的精确路径（例如新增文件）可以新建，**不依赖 CAB 索引**：安装前弹一次汇总窗列出全部待新建文件，点「全部新建」按归一化后的路径写入，点「只跳过新增」这些文件不装、已有资源照常安装。日志会分别记 `该路径没有对应资源，按精确路径新建` 与 `已将 X 移动到 Y`。新建范围是 `files` 下的真实一级目录，拒绝绝对路径、`..`、`assets/`。说明 / 预览文件里只有真正的游戏文本（`localmode.txt`、`serverlist*.txt`、`LocalSetting.txt`、资源目录下的 txt）才按资源安装，作者的 `说明.txt`、`安装说明.txt` 不覆盖游戏自带文档；png/jpg/md 一律不部署。

## 安全设计

- 备份按包名隔离：`备份文件/<包名>/原版/`，官服与渠道服互不覆盖；
- 覆盖前先备份，写 `.manifest.tsv`（rel / cksum / size），APP 回滚直接读取；
- 说明文件不备份、不回滚；
- 备份校验不符会逐条告警，回滚会跳过异常文件；
- 本仓库不含签名密钥，发布包也不含。

## 自己编译

`build.sh` 不写死本机路径，所需环境变量：

| 变量 | 说明 |
|---|---|
| `ANDROID_TOOLS` | 工具根目录，含 `android-34/android.jar`、`sysroot/.../aapt`、`zipalign`、`r8.jar`、`apksigner.jar`、Shizuku 四个 `classes.jar` |
| `JAVA_HOME` | 可选，JDK 17+ |
| `KS_FILE` | 可选，签名密钥库，默认 `./keystore.jks` |
| `KS_PASS` / `KEY_PASS` | 密钥库与密钥口令，通过环境变量传入 |
| `ANDROID_TOOLS_LD` | 可选，aapt 需要的 `LD_LIBRARY_PATH` |

构建前会逐个检查依赖，缺哪个会直接报出完整路径。签名密钥请自行离线保存，不要提交到仓库。

```
├── 补丁存放位置（zip）/     ← 要装的 zip 放这里
├── 备份文件/<包名>/原版/    ← 原版备份 + .manifest.tsv
├── 补丁素材源文件/          ← 打包临时目录
├── 打包补丁/待打包资源/     ← 打包源
├── 操作日志/
├── 临时解压/
└── 缓存/资源索引/
```

- **v3.15.1 本地版**：真机实测原生扫描 875s/28515 行仍是 32 条/秒，确认瓶颈在 FUSE；root 通道建表扫描根改走 `/data/media/0` 直连并记日志，Shizuku 通道不变。
