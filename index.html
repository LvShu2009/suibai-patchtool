安装前请先在系统里授予「所有文件访问」；执行身份二选一：Shizuku 授权，或设备 root 直接授权。

三分钟用起来

  1. 安装 APK（覆盖安装不会丢配置）
  2. 选执行通道：有 root → 勾「优先用 root」；没 root → 点「① 授权 Shizuku」
  3. 点「② 文件访问权限」，在系统设置里给「所有文件访问」
  4. 把补丁 zip 放进 LvShu/酸败补丁/补丁存放位置（zip）/
  5. 确认游戏目录（官服 com.jumpw.mobile300，渠道服点「自动探测」）
  6. 点「▶ 一键安装补丁」，跑完会弹结果框，可直接打开游戏

安全与回滚

  • 覆盖前自动备份原版到 备份文件/<包名>/原版/，同一文件只备份一次，重复跑不会重复备份
  • 「↩ 一键回滚原版」按索引逐字节校验后还原，校验不符的文件会被拒绝，避免盖错
  • 反和谐为 localmode.txt 空文件开关，「🧹 清理备份」可释放空间并保留原版
  • 详细日志在 操作日志/，每次运行一个文件
